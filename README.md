# Mege Sandbox

A simple grid-based sandbox game built with C and Raylib

## Requirements

- CMake
- Raylib
- C compiler (GCC or Clang)

## Build and Run

Run the following commands in order:

```bash
cmake -B build
cmake --build build
./build/mege-sandbox
```
